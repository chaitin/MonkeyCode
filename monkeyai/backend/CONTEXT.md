# MonkeyAI 后端

MonkeyAI 后端统一服务管理后台和工作 Agent，负责单实例内的用户身份、AI 资源、会话用量、积分计费与管理审计。系统不承担多租户能力，所有业务数据天然属于当前实例。

## 系统与身份

**系统**:
一套独立部署并服务固定用户集合的 MonkeyAI 实例，是配置、数据和权限的最高边界。
_避免_: 团队、租户、组织、工作空间

**用户**:
可登录当前系统的人员身份，同时包含管理角色、启停状态和个人资料；管理页面当前称其为“成员”。
_避免_: 成员、员工、团队成员

**分组**:
按树形结构组织用户的授权和额度继承单元；选择父分组时包含其所有后代分组。界面根节点表示整个系统，不是普通分组。
_避免_: 部门、角色

**工作 Agent**:
运行在用户客户端、从系统获取授权资源并发起、执行和上报会话的 AI 程序。
_避免_: 专家、管理后台、用户

**调用密钥**:
用户通过全局 API 创建、授权给工作 Agent 调用模型或 MCP 服务的长期凭据。密钥认证调用用户及 scope，MCP 地址确定连接和具体凭证，服务端实时校验用户访问权；与登录会话凭据相互独立。
_避免_: 登录 Token、模型供应商密钥、LLM Key

## 资源与授权

**资源归属**:
资源归系统或某个用户所有的分类。分享仅改变访问授权，不改变资源归属；当前用户看到的自有或他人分享资源都属于个人资源。
_避免_: 资源来源、分享状态

**系统资源**:
由管理员创建和维护、归系统所有并供被授权用户共同使用的模型、规则、技能或 MCP 服务。
_避免_: 团队资源、管理员资源

**个人资源**:
由某个用户持有、可授权给其他用户或分组使用的 AI 资源。
_避免_: 用户资源、私有资源

**资源访问授权**:
将一项资源以指定访问级别授予一个用户、分组或全体用户；分组授权覆盖其所有后代分组中的用户。
_避免_: 访问范围、权限列表、白名单

**全员授权**:
将资源授予当前系统的全体用户，包含之后新增的用户；在授权界面通过选择根节点表达。
_避免_: 全选成员、根分组成员快照

**模型**:
可被会话调用的一项大模型配置，包含协议、上下文能力、凭据和积分倍率。
_避免_: 模型供应商、模型实例

**技能**:
以技能包交付、为 Agent 提供专门工作方法和配套文件的可授权资源。ZIP 中的 `SKILL.md` 是名称、描述和正文的权威来源，包字节保存在 RustFS，数据库保存摘要与对象引用。
_避免_: 插件、工具

**规则**:
约束 Agent 行为或输出的文本指令；系统规则可以被强制应用，个人规则不能被管理员强制应用。
_避免_: 提示词、策略

**MCP 服务**:
通过连接（Connector）提供一组可发现工具的远程服务，使用时可以无需认证、共用集中凭证，或选择用户自己的独立凭证。
_避免_: 工具、插件

**MCP 工具**:
由 MCP 服务暴露的单个可调用能力，可独立启停和配置每次调用积分。
_避免_: MCP 服务

**专家**:
由角色提示词、默认模型、连接依赖、规则和技能组合而成的系统或个人 Agent 预设；系统专家对固定系统规则和技能的委托读取权不扩散为独立资源访问权，个人专家的接收方仍需获得依赖资源的使用授权。
_避免_: 助手、机器人

## 执行与计费

**会话**:
用户从某个客户端发起并持续到完成、失败或取消的一次 Agent 工作单元。
_避免_: 任务、请求

**模型调用**:
会话执行期间向一个模型发起的一次请求，是成功率、时延和 Token 用量的事实记录。
_避免_: 模型用量、推理任务

**积分**:
MonkeyAI 对模型和工具用量进行统一计价的内部单位。
_避免_: 金额、Token

**额度**:
每个刷新周期分配给分组或用户的积分上限；未单独设置时从最近上级分组继承。
_避免_: 余额、预算

**积分账户**:
记录用户在当前额度周期内可用积分余额的账户。
_避免_: 额度、钱包

**计费流水**:
积分账户每次扣减、发放、退款、重置或人工调整形成的不可变记录。
_避免_: 用量、账单

**审计记录**:
管理员或系统执行管理操作后形成的不可变事实，保留操作者和目标对象的必要快照。
_避免_: 运行日志、调试日志

**全局设置**:
在当前系统中唯一且对所有用户生效的品牌、登录、邮件和计费规则集合。
_避免_: 团队设置、用户偏好

## 资源连接与分发

**连接（Connector）**：可被授权、分享和启停的一项远程 MCP 服务配置，自身定义目标服务及认证方式。
_避免_: 连接模板、Provider

**连接凭证**：访问一个连接所需的上游认证信息。独立凭证属于某个用户，同一用户在同一连接下可以持有多份；集中凭证供获准使用连接的用户共用。
_避免_: 调用密钥、上游账户

**认证上下文**：一个连接下选定的具体凭证，或免认证连接的无凭证状态；不同认证上下文可以发现不同的工具。

**凭证绑定**：用户明确选择某个连接所使用的独立凭证，客户端通过该凭证的 MCP 地址固定调用上下文。集中凭证也有具体地址；所有代理地址以 `/mcp` 为前缀，同一全局调用密钥可供多个地址使用。共享专家只声明连接依赖，不替用户选择凭证。

**资源清单**：服务端按用户权限解析专家依赖与显式选择后产生的规则正文、技能包元数据和连接目录。清单的 SHA-256 版本是变更判断依据。
