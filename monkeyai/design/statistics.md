# 管理后台统计

四个统计页面使用 `/api/admin/v1/statistics/{realtime,models,tasks,history}`，由 `internal/stats` 显式注册并复用管理员 Cookie 鉴权。Agent token 和调用密钥没有访问权限。查询使用 PostgreSQL 只读 Repeatable Read 快照，单次请求限时 15 秒，返回 `private, no-store`。

## 数据口径

| 页面 | 数据来源 | 时间与计算规则 |
| --- | --- | --- |
| 模型统计 | `model_calls`、`models`、`credit_ledger_entries` | 调用按 `started_at`，积分按 `occurred_at`；模型筛选同时作用于调用和消费。缓存命中率为命中缓存的调用数 / 全部调用数。输入 Token 已包含缓存输入，不能再次累加。 |
| 实时状态 | `model_calls`、`mcp_tool_calls`、`billing_transactions`、`sessions`、积分流水 | 吞吐与时延按窗口内完成的模型调用；RPM、TPM 分别除以整个窗口分钟数。成功率分母包含失败和取消，排除运行中记录。P95 优先使用响应耗时，未记录时取完成时间减开始时间。 |
| 任务统计 | `sessions` | 按开始时间选择新建会话，按当前结束结果分类：未结束、成功结束、异常结束。完成率为成功结束数 / 全部会话数；平均耗时仅取已结束会话。取消若以失败字段记录，归入异常结束。 |
| 任务历史 | `sessions`、`users` | 按开始时间倒序并以 UUID 稳定排序；支持标题 / UUID、姓名 / 邮箱包含搜索，以及日期和分页。只展示累计轮次，不把它解释为窗口内新增对话数。 |

- 统计周期为相对于服务端当前时间的滚动窗口，统一使用 `[from, until)`；环比查询紧邻的上一等长周期。
- 24 小时趋势按 1 小时分桶，7 / 30 / 90 天趋势按固定 24 小时分桶，从窗口起点开始，空桶补零，不对齐自然日。页面标签按浏览器语言及时区格式化。
- 积分净消费只累加 `category=model` 的 `charge` 和 `refund`，扣除退款；额度发放、重置、人工调整不计入模型消费。纯退款窗口允许负值。调用与积分独立聚合，避免多笔流水放大调用量。
- 积分通过 PostgreSQL `numeric` 聚合并以十进制字符串返回，前端仅在展示和绘图时转为数值，不参与计费。
- 无调用时成功率、缓存命中率及 P95 为 `null`；无已结束会话时平均耗时为 `null`，页面显示 `—`。上一周期为零时不展示数量增长率；比率指标环比使用百分点。
- 已软删除模型的历史调用和消费保留，模型选项包含窗口内有历史事实的已删除模型。已软删除会话不进入任务统计与历史。
- 实时活跃用户按有完成模型 / MCP 调用、有会话活动、或窗口内发起且仍在执行计费调用的真实用户 ID 去重，不代表登录 DAU。活跃任务仅指近期有活动的未结束会话。
- 实时页每 30 秒刷新，标签页隐藏时暂停自动请求。筛选变化会中止旧请求，旧响应不覆盖新筛选结果；网络错误提供重试。

## 会话采集边界

当前模型 / MCP 网关已经通过计费生命周期记录调用事实，模型统计可直接使用这些数据。

当前 `internal/session` 尚未实现会话上报，Desktop / Agent 也没有接通此表。本次只完善管理端统计读取，没有新增客户端采集协议。因此新部署中的任务统计、任务历史以及实时任务指标在接通会话采集前为空；页面明确说明这一依赖，不生成示例数据，也不将一次模型请求伪装成一个任务。历史已有会话事实的实例可直接查询。

## 迁移与验证

新增 `000004_stats_add_indexes`，为模型调用开始 / 完成时间、MCP 完成时间以及会话开始 / 活跃时间补充索引。部署前执行增量迁移至版本 4。该版本仅添加索引，可以单独 down / up；大量历史数据下建索引会占用写锁，按既有迁移发布流程安排维护窗口。

验证使用独立 PostgreSQL / RustFS 测试容器：

- 统计集成测试覆盖左闭右开边界、真实环比、退款净额、模型隔离、软删除历史、空桶、长调用跨窗口、P95 缺失耗时回退、任务分类、筛选与分页。
- 应用集成测试通过真实模型 / MCP 计费入口产生事实，再访问统计路由，并校验匿名访问和 Agent token 被拒绝。
- 前端测试覆盖零基数环比和百分点口径，同时执行已有测试、lint、build。
- OpenAPI 检查重复键、本地引用以及迁移序号；新增迁移在空库执行 up / down / up。

本轮验证结果：后端完整 PostgreSQL / RustFS 集成测试、`go vet ./...`、统计模块 race 测试、前端 45 项测试、lint 和生产构建通过。浏览器使用独立测试数据验证模型筛选、任务状态与历史分页、空结果、网络错误重试、延迟旧请求隔离和 390 像素布局。统计图表关闭入场动画，避免隐藏标签页停留在空白初始帧；图例直接引用主题颜色，使图表容器外的状态标识正常显示。
