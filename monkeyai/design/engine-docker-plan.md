目标：使用 Docker Engine + runsc 替换专用 containerd/CNI，保持后台、客户端、持久目录及生命周期协议。

- 已完成：Docker API 驱动、固定摘要镜像、CPU/内存/进程/tmpfs 约束、实例归属、镜像缓存和 standalone 执行。
