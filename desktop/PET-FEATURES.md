## 积分口径

- 「积分余额」为现有钱包 `balance / 1000`，是当前可用积分；不是历史累计到账积分，接口暂无后者的聚合字段。
- 「今日已用」按北京时间当天，从积分流水接口完整翻页汇总模型、主机和 MCP 工具消费的 `amount_balance / 1000`。不计免费 Token、每日免费部分、充值/赠送、订阅购买和罚款，包含同账号其他客户端的使用。
- 每次固定查询起止时间，最多 50 页、10 秒；接口不可用、字段缺失或翻页未完成显示「—」，不显示部分结果或假 0。
- 普通刷新 60 秒，点击可刷新（最低间隔 5 秒）；跨日不沿用昨日消费，账号切换清除旧数据，缓存有明确标记。

## 验证范围

测试覆盖播放缓存、快速触摸、异步播放取消、导入限制/失败、偏好迁移、提醒优先级、积分消费分页和跨日显示。浏览器验证采用真实前端和音频，账号及文件存储桥接使用测试数据；不替代真实云端账号及 Windows 原生窗口验收。
