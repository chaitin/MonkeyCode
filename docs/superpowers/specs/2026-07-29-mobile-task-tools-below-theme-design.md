# 手机任务工具入口移至主题按钮下方设计

## 背景

手机任务详情页的三点工具入口位于控制台全局主题切换按钮下方。入口需要保持现有横向位置，同时调整垂直位置，使其中心与任务页模型按钮中心精确处于同一水平线。

## 目标

1. 三点工具入口仅在手机任务详情页显示。
2. 三点入口位于主题切换按钮正下方，两个按钮右边线对齐。
3. 三点入口使用与主题切换按钮相同的 32px × 32px 尺寸。
4. 三点入口中心与 28px 高的模型按钮中心精确处于同一水平线。
5. 工具菜单内容、文件视图、动作时序和关闭行为保持现状。
6. 桌面任务页和其他控制台页面保持现状。

## 布局

### 定位基准

- 控制台全局顶栏高度为 60px，主题按钮位于顶栏右侧 16px 内边距处。
- 三点入口在任务详情组件中使用手机端固定定位 `fixed right-4 top-[58px]`。
- `right-4` 让三点入口与主题按钮共享距离视口右侧 16px 的边线。
- 任务页内容从 60px 高的全局顶栏下方开始，28px 模型按钮的中心位于视口顶部 74px。
- 32px 三点按钮使用 58px 顶距，其中心同样位于视口顶部 74px。
- 三点入口使用 `z-30`，确保入口位于任务内容上方并保持可点击。

### 入口尺寸

- 三点入口继续使用 `Button variant="outline"`。
- 按钮尺寸改为 `size="icon-sm"`，与 `ModeToggle` 的主题按钮一致，计算尺寸为 32px × 32px。
- `IconDots` 继续使用 16px 图标和现有可访问名称。

### 任务页安全空间

- 三点入口从任务页页头 Flex 流中移出。
- 手机任务页页头右侧保留 40px 安全空间，覆盖 32px 按钮和 8px 间距，防止模型或上下文内容进入固定入口区域。
- 桌面断点清除该安全空间。
- 模型按钮继续使用已确认的 28px 高度、内容自适应宽度、220px 最大宽度和窄屏收缩规则。
- 上下文圆环继续使用 20px 可见尺寸。

## Popover 与状态

- `mobileToolsOpen`、`mobileToolsView`、`pendingMobileToolActionRef` 和所有处理函数继续由任务详情组件管理。
- `Popover`、`PopoverTrigger` 与 `PopoverContent` 保持同一组件树，避免跨路由 context、Portal 插槽或状态提升。
- 工具菜单继续使用 `side="bottom"`、`align="end"`、`sideOffset={6}` 和 `avoidCollisions={false}`。
- 工具菜单视图继续为 104px 宽，文件视图继续使用 `calc(100vw - 2rem)` 且最大 420px。
- Skills、文件、预览和发布动作保持现有关闭后执行时序。

## 响应式范围

- 固定三点入口使用 `md:hidden`，仅在手机断点显示。
- 桌面工具栏继续显示现有 Skills、终端、文件、预览和发布按钮。
- 任务详情组件卸载时，固定入口随组件自然卸载。
- 其他控制台页面不会渲染该入口。

## 可访问性

- 三点入口保留原生按钮语义和“更多任务工具”可访问名称。
- 主题按钮与三点入口各自保留独立焦点顺序。
- Popover 的打开、关闭、焦点恢复和后续 Dialog 时序保持现状。

## 测试与验收

### 自动测试

1. 手机三点入口包含 `fixed right-4 top-[58px] z-30 md:hidden`。
2. 三点按钮使用 `size="icon-sm"`，并移除 28px `size-7` 尺寸。
3. 测试锁定 60px 顶栏、28px 模型按钮和 32px 三点按钮的中心对齐公式。
4. 任务页页头包含手机 40px 右侧安全空间和桌面清除规则。
5. 三点入口仍位于唯一的手机工具 `Popover` 内。
6. 工具菜单宽度、文件视图宽度、动作时序和桌面工具栏契约继续通过。
7. 运行聚焦测试、ESLint、TypeScript、完整测试和 online build。

### 人工验收

在 320px、375px、390px、430px 和 1280px 下检查：

- 手机任务页三点按钮位于主题按钮正下方，右边线精确对齐。
- 三点按钮中心与模型按钮中心精确处于同一水平线。
- 两个按钮均为 32px × 32px，边框、圆角和视觉重量一致。
- 模型和上下文区块与三点入口之间无覆盖。
- 工具菜单向下展开，所有工具和文件视图可正常使用。
- 离开任务页后固定三点入口消失。
- 桌面任务页和其他控制台页面保持现状。

## 非目标

- 本次范围不向控制台外壳增加任务操作插槽。
- 本次范围不引入跨路由 context 或额外 Portal 容器。
- 本次范围不修改主题切换按钮和主题菜单。
- 本次范围不修改工具菜单业务动作、消息定位或历史加载。
