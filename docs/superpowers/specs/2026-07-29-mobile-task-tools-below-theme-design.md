# 手机任务工具入口模型行锚定与消息定位动作尺寸设计

## 背景

手机任务详情页的三点工具入口位于控制台全局主题切换按钮下方。入口需要保持现有横向位置，同时与任务页模型按钮共享布局和滚动参考系，使两个按钮的中心始终处于同一水平线。

此前采用 `fixed right-4 top-[58px]` 并通过 React Portal 挂载到 `document.body`。该方案依据全局顶栏高度计算固定顶距；手机页面滚动后，模型行相对视口的位置会变化，三点入口仍保持固定顶距，因此产生动态垂直偏移。

消息定位面板底部的“滑到底部”动作当前在手机端高于顶部“加载更多”动作。两个面板动作需要使用相同高度，形成一致的视觉节奏。

## 目标

1. 三点工具入口仅在手机任务详情页显示。
2. 三点入口位于主题切换按钮正下方，两个按钮右边线对齐。
3. 三点入口使用与主题切换按钮相同的 32px × 32px 尺寸。
4. 三点入口中心与 28px 高的模型按钮中心精确处于同一水平线。
5. 工具菜单内容、文件视图、动作时序和关闭行为保持现状。
6. 桌面任务页和其他控制台页面保持现状。
7. 滚动任务页面时，三点入口与模型区块同步移动并保持垂直居中。
8. 消息定位面板的“滑到底部”与“加载更多”动作均为 32px 高。

## 布局

### 定位基准

- 控制台全局顶栏的主题按钮位于右侧 16px 内边距处。
- 任务页模型行容器增加 `relative` 定位上下文。
- 三点入口作为模型行容器的子元素，使用 `absolute right-0 top-1/2 z-30 -translate-y-1/2 md:hidden`。
- 任务页内容具有 16px 水平内边距，`right-0` 让三点入口与主题按钮共享距离视口右侧 16px 的边线。
- `top-1/2 -translate-y-1/2` 让 32px 三点按钮以模型行实时中心为垂直基准，垂直定位完全由模型行决定。
- 三点入口与模型行共享滚动参考系；模型行位置变化时，入口同步移动。
- 三点入口使用 `z-30`，确保入口位于任务页头内容上方并保持可点击。

### 入口尺寸

- 三点入口继续使用 `Button variant="outline"`。
- 按钮尺寸改为 `size="icon-sm"`，与 `ModeToggle` 的主题按钮一致，计算尺寸为 32px × 32px。
- `IconDots` 继续使用 16px 图标和现有可访问名称。

### 任务页安全空间

- 三点入口使用绝对定位，任务页页头 Flex 流保留完整可用宽度。
- 手机任务页页头右侧保留 40px 安全空间，覆盖 32px 按钮和 8px 间距，防止模型或上下文内容进入入口区域。
- 桌面断点清除该安全空间。
- 模型按钮继续使用已确认的 28px 高度、内容自适应宽度、220px 最大宽度和窄屏收缩规则。
- 上下文圆环继续使用 20px 可见尺寸。

## Popover 与状态

- `mobileToolsOpen`、`mobileToolsView`、`pendingMobileToolActionRef` 和所有处理函数继续由任务详情组件管理。
- `Popover`、`PopoverTrigger` 与 `PopoverContent` 保持为模型行容器内的同一 React 子树。
- 入口直接使用任务详情组件的既有 React 子树、context 和状态。
- 工具菜单继续使用 `side="bottom"`、`align="end"`、`sideOffset={6}` 和 `avoidCollisions={false}`。
- 工具菜单视图继续为 104px 宽，文件视图继续使用 `calc(100vw - 2rem)` 且最大 420px。
- Skills、文件、预览和发布动作保持现有关闭后执行时序。

## 响应式范围

- 三点入口使用 `md:hidden`，仅在手机断点显示。
- 桌面工具栏继续显示现有 Skills、终端、文件、预览和发布按钮。
- 任务详情组件卸载时，入口随组件自然卸载。
- 其他控制台页面不会渲染该入口。

## 消息定位面板动作尺寸

- 顶部“加载更多”动作继续使用 `h-8`，外层继续使用 `p-1.5`。
- 底部“滑到底部”动作统一使用 `h-8`，移除手机端 `h-11` 和桌面覆盖类 `md:h-8`。
- “滑到底部”的图标、文案、颜色、点击行为和自动收起行为保持现状。
- 面板宽度、最大高度、消息条目高度和定位圆点保持现状。

## 可访问性

- 三点入口保留原生按钮语义和“更多任务工具”可访问名称。
- 主题按钮与三点入口各自保留独立焦点顺序。
- Popover 的打开、关闭、焦点恢复和后续 Dialog 时序保持现状。

## 测试与验收

### 自动测试

1. 手机模型行包含 `relative` 定位上下文，三点入口包含 `absolute right-0 top-1/2 z-30 -translate-y-1/2 md:hidden`。
2. 三点按钮使用 `size="icon-sm"`，并移除 28px `size-7` 尺寸。
3. 测试锁定三点入口位于模型行子树内，并验证入口已移除 `createPortal`、`document.body`、`fixed` 和 `top-[58px]` 定位。
4. 任务页页头包含手机 40px 右侧安全空间和桌面清除规则。
5. 三点入口仍位于唯一的手机工具 `Popover` 内。
6. 工具菜单宽度、文件视图宽度、动作时序和桌面工具栏契约继续通过。
7. 运行聚焦测试、ESLint、TypeScript、完整测试和 online build。
8. 消息定位面板的“加载更多”和“滑到底部”动作均使用 `h-8`，后者不再包含响应式高度覆盖类。

### 人工验收

在 320px、375px、390px、430px 和 1280px 下检查：

- 手机任务页三点按钮位于主题按钮正下方，右边线精确对齐。
- 三点按钮中心与模型按钮中心精确处于同一水平线。
- 两个按钮均为 32px × 32px，边框、圆角和视觉重量一致。
- 模型和上下文区块与三点入口之间无覆盖。
- 工具菜单向下展开，所有工具和文件视图可正常使用。
- 上下滚动任务页面时，三点入口与模型区块同步移动并始终保持同一水平线。
- 消息定位面板的“加载更多”和“滑到底部”高度一致。
- 离开任务页后三点入口消失。
- 桌面任务页和其他控制台页面保持现状。

## 非目标

- 本次范围不向控制台外壳增加任务操作插槽。
- 本次范围不引入跨路由 context 或全局状态提升。
- 本次范围不修改主题切换按钮和主题菜单。
- 本次范围不修改工具菜单业务动作、消息定位算法或历史加载行为。
