# 移动端英文工具菜单宽度设计

## 背景

任务详情页的移动端更多工具菜单当前宽度为 104px。英文环境下，`Skills`、`Preview` 和 `Publish` 会因可用文本宽度不足而显示省略号。

## 目标

将工具视图宽度增加至 120px，并将文件与预览计数移入图标角标，使 `Skills`、`Files`、`Preview` 和 `Publish` 在英文环境下完整显示，同时维持现有紧凑布局和交互行为。

## 设计

- 将工具视图的固定宽度从 104px 调整为 120px。
- 菜单继续右对齐，右边线位置保持不变，新增宽度向左侧扩展。
- 操作行继续使用 44px 高度、现有图标、8px 图文间距和 12px 水平内边距。
- 文件变更数和预览端口数显示为对应图标右上角的主色数字角标，释放标签右侧空间。
- 文件和预览按钮的无障碍名称继续包含当前计数。
- 文件视图继续使用 `calc(100vw - 2rem)`，最大宽度保持 420px。
- 三点入口尺寸、模型行锚定、Popover 展开方向、关闭时序和业务动作保持现状。
- 中文环境继续使用同一 120px 宽度，避免语言切换引起菜单外框跳动。

## 测试

- 更新移动端页头布局测试，将工具菜单宽度契约从 104px 改为 120px。
- 增加文件与预览计数角标结构测试，确保计数不再占用标签右侧宽度。
- 保留文件视图宽度、44px 操作行、Popover 对齐和模型行锚定断言。
- 运行移动端聚焦测试、ESLint、TypeScript 和 online build。
- 在英文环境下人工确认四个工具名称完整显示，并在 320px 宽度确认菜单未超出视口。

## 范围

本次仅调整移动端工具视图宽度、文件与预览计数呈现，以及对应测试和设计记录。桌面工具栏、文案、文件视图尺寸、业务动作与消息定位行为保持现状。
