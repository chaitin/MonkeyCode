# 手机页头原始尺寸与消息定位避让设计

## 背景

任务页手机端页头为了提供较大的触控区域，将模型按钮、上下文入口和三点按钮统一扩展到了 44px。该尺寸高于官方原始页头控件，导致顶部区域显得偏大。消息区右侧的官方定位圆点条在手机端收起时还会覆盖少量消息内容。

本次恢复页头控件的官方可见尺寸，同时保留已经确认的 104px 工具菜单精确对齐。消息定位继续使用官方单一右侧面板，并通过手机端内容避让消除收起状态的遮挡。

## 目标

1. 手机端模型按钮恢复官方 28px 高度。
2. 手机端上下文圆环恢复官方 20px 可见尺寸。
3. 手机端三点按钮恢复 28px × 28px 紧凑尺寸。
4. 工具菜单继续保持 104px 宽度，左边线继续与模型按钮右边线精确重合。
5. 官方消息定位圆点条在手机端收起时不覆盖消息文字或气泡。
6. 保留消息定位的加载历史、跳转消息、回到底部、触摸展开和外部收起行为。
7. 桌面端页头和消息定位布局保持现状。

## 页头布局

### 模型按钮

- 手机端与桌面端均使用官方 `h-7`，高度为 28px。
- 手机端恢复官方按模型名称自适应的宽度，最大宽度为 220px，短名称保持紧凑比例。
- 保留 `min-w-0`、文本截断和 flex 收缩能力，使长名称在 320px 宽度下按需缩短。
- 桌面端继续使用最大宽度 220px。
- 图标、文案、禁用条件和模型切换行为保持不变。

### 上下文入口

- `CircularProgress` 继续使用官方 `size={20}`。
- 手机端移除 44px 可见按钮外框，恢复紧凑的 20px 圆环外观。
- 圆环位于 44px 宽的布局槽内。该槽位在上下文入口缺省时继续保留，用于维持菜单边线对齐。
- 触摸展开、键盘焦点、可访问名称和上下文操作行为保持不变。

### 三点入口

- 三点按钮使用 28px × 28px 可见尺寸，继续展示 `IconDots`。
- 按钮位于 44px 宽的布局槽内并贴右对齐。
- 保留“更多任务工具”可访问名称、Popover 关闭行为和焦点恢复。

### 104px 对齐轨道

手机端模型按钮右侧继续保留以下尾部轨道：

```text
8px 间距 + 44px 上下文槽位 + 8px 间距 + 44px 三点槽位 = 104px
```

104px 尾部轨道紧跟自适应宽度的模型按钮。三点按钮在最后一个槽位内贴右，因此按钮右边线仍是尾部轨道右边线。工具 Popover 保持 `align="end"` 和 104px 宽度，菜单左边线继续与模型按钮右边线重合。

## 消息定位避让

### 收起状态

- 保留官方圆点尺寸、圆点间距、圆角、边框、背景、阴影和右侧居中位置。
- 手机端移除后来增加的 44px 最小可见尺寸约束，恢复官方紧凑圆点条外形。
- 消息列表内容区域在手机端预留 44px 右侧安全槽，使消息文字和气泡边界位于圆点条左侧。
- 安全槽只影响消息内容宽度，不改变滚动容器宽度、滚动条位置和定位面板绝对定位基准。

### 展开状态

- 点击或触摸圆点条后继续展开官方消息列表。
- 展开面板继续作为临时浮层覆盖消息区域，宽度和最大高度保持现状。
- 选择消息、点击外部或执行回到底部后继续收起面板。
- 本次遮挡修复聚焦用户确认的收起状态。

### 桌面端

- 桌面端消息内容宽度和定位面板尺寸保持现状。
- 手机端安全槽通过响应式 class 限定，在桌面断点恢复原布局。

## 状态与数据流

- 不新增状态、全局 store 或测量逻辑。
- 页头尺寸和安全槽仅通过响应式 CSS class 实现。
- `TaskUserInputIndex` 继续接收现有消息、历史加载、滚动容器、跳转和回到底部参数。
- 不修改消息索引计算、历史分页或虚拟列表滚动算法。

## 可访问性

- 模型和三点按钮继续保留原生按钮语义及可访问名称。
- 上下文入口继续支持键盘焦点和触摸展开。
- 定位圆点条继续使用按钮语义、`aria-label` 和 `aria-expanded`。
- 手机端缩小可见控件是恢复官方原始尺寸的明确产品决策。

## 测试与验收

### 自动测试

1. 模型按钮在手机端和桌面端均包含 `h-7`，使用内容自适应宽度、220px 最大宽度和窄屏收缩规则。
2. 上下文圆环保持 `size={20}`，手机端可见按钮不再使用 `size-11`。
3. 三点按钮使用 28px × 28px 可见尺寸，并位于 44px 贴右布局槽内。
4. 104px 尾部轨道和 `w-[104px]` 工具菜单继续存在。
5. 消息内容仅在手机端增加 44px 右侧安全槽。
6. 定位圆点条继续保持单一实例及现有交互契约。
7. 运行聚焦测试、ESLint、TypeScript、完整测试和 online build。

### 人工验收

在 320px、375px、390px、430px 和 1280px 下检查：

- 手机端模型按钮按名称自适应宽度且最大为 220px；模型按钮和三点按钮高度为 28px，上下文圆环为 20px。
- 手机页头保持单行且不产生横向滚动。
- 104px 工具菜单左边线与模型按钮右边线精确重合。
- 上下文入口显示和缺省两种状态下，对齐关系保持一致。
- 收起的消息定位圆点条不覆盖消息文字或气泡。
- 展开、消息跳转、加载历史、回到底部和外部收起正常工作。
- 桌面端页头、消息宽度和定位面板保持现状。

## 非目标

- 不修改工具菜单内容、文件视图或业务动作。
- 不改变展开消息定位面板的临时覆盖行为。
- 不改变消息索引、历史分页或虚拟列表算法。
- 不新增依赖、全局状态、Drawer、第二个定位入口或 JavaScript 几何测量。
